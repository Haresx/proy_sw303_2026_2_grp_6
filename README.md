# Ingenieria Mecanica:simulador de vibraciones mecanicas
### Descripcion del proyecto
El sistema calculará el desplazamiento y la velocidad de una masa sometida a una fuerza externa a lo largo
del tiempo. Usará integración numérica para aproximar la solución de la ecuación diferencial y
representará gráficamente la respuesta.

### Beneficios de la aplicacion 
Esta aplicación funciona como un laboratorio virtual para predecir cómo se moverá un objeto al recibir distintos empujes o fuerzas, sin tener que construirlo en la vida real ni resolver ecuaciones eternas a mano. Te permite cambiar datos como el peso o la intensidad de la fuerza y ver al instante, en gráficos fáciles de entender, si el objeto se mantiene estable, si vibra demasiado o si termina fallando, ahorrándote tiempo, dinero y dolores de cabeza antes de pasar al mundo físico.
